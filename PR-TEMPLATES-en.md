## Where to put the link

| Platform | Link to use | Where |
|---|---|---|
| **Facebook** (post/reel caption) | `https://yourdomain.com/?fb=1` | In the caption text, one link only |
| **YouTube** | `https://yourdomain.com/` | In the description (first 2 lines) |
| **TikTok / Instagram** | `https://yourdomain.com/` | In the caption or bio |
| **Telegram channel** | `https://yourdomain.com/` | In the post |

> On Facebook always use `?fb=1` — it hides the 18+ box so Meta's crawler sees a clean page.
> Never put the `t.me` link directly in a Facebook post. Keep it inside the description only.
